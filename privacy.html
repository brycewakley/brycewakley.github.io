Privacy Policy

Synology Rclone Backup is a personal application used to back up authorized Google Drive files.

Data Access

The application uses read-only access to Google Drive files and file metadata.

Data Storage

Selected files are copied directly to a privately owned Synology NAS for backup.

Data Sharing

Google user data is not sold, used for advertising, or shared with third parties by this application.

Data Retention and Deletion

Backup files are retained until manually deleted by the application owner. Google access can be revoked at any time through Google Account security settings.

Security

Authentication credentials are stored privately on the NAS and are not published on this website.
